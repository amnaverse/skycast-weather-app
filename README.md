# 🌤️ SkyCast — Weather Forecasting App

A real-time weather forecasting app built with React.js and Vite, using live data from the Open-Meteo API.

**🔗 Live Demo:** https://amnaverse.github.io/skycast-weather-app/

## Features
- 🌍 Real-time weather data from the Open-Meteo API
- 📍 Geolocation-based search
- 🎨 Custom hand-drawn weather icons
- 📱 Responsive, mobile-friendly UI
- 🧩 Component-based architecture

## Tech Stack
- **Frontend:** React.js, Vite
- **API:** Open-Meteo

## How to Run Locally
```bash
git clone https://github.com/amnaverse/skycast-weather-app.git
cd skycast-weather-app
npm install
npm run dev
```

The app runs on `http://localhost:5173`.
